# 教程 5: 结果解读与发表

> 目标时长：10 分钟
> 目标受众：需要将分析结果转化为论文图表的研究者
> 目标：学会正确解读图表、判断统计显著性、导出符合期刊规范的结果

### 第一部分：图表解读基础（0:30-2:30）

#### 箱线图解读（0:30-1:15）

**[画面]**：展示 Alpha 多样性箱线图，标注各元素含义

**[解说词]**：
> "箱线图是微生物组分析中最常见的图表。让我解释每个元素的含义：箱子中间的横线是中位数，代表数据的中心位置。箱子的上下边界分别是第一四分位数和第三四分位数，包含了 50% 的数据。箱子的长度叫四分位距，反映数据的离散程度。箱子外的 whiskers 通常延伸到 1.5 倍四分位距。超出 whiskers 的点称为异常值。"

**[画面]**：悬停在箱线图上，显示具体数值

**[解说词]**：
> "解读箱线图时，我们主要关注两组中位数的位置差异。如果两组的中位数差异明显，且统计检验显著，可以认为存在组间差异。注意：如果箱子重叠很多，即使统计显著，实际差异可能也很小。"

#### 散点图（PCoA）解读（1:15-2:00）

**[画面]**：展示 PCoA 散点图，标注各元素含义

**[解说词]**：
> "PCoA 散点图展示样本间的相似性关系。每个点代表一个样本，颜色代表分组。距离相近的点表示群落组成相似，距离远的点表示差异大。如果相同颜色的点聚集在一起，不同颜色的点分散，说明分组对群落结构有显著影响。"

**[画面]**：标注坐标轴百分比

**[解说词]**：
> "坐标轴标签上的百分比表示该轴解释的总差异比例。比如第一轴解释 35% 的差异，第二轴解释 20%，说明这两个维度共解释了 55% 的差异，降维效果较好。如果前两个轴的百分比之和小于 30%，说明降维效果不佳，群落差异可能过于复杂。"

#### 火山图解读（2:00-2:30）

**[画面]**：展示火山图，标注各区域含义

**[解说词]**：
> "火山图展示差异分析的结果。X 轴是 log2 倍数变化，正值表示处理组上调，负值表示下调。Y 轴是负对数 P 值，越高表示统计显著性越强。右上角的点是处理组显著上调的特征，左上角是显著下调的特征。灰色的点是不显著的特征。"

---

### 第二部分：统计显著性判断（2:30-4:30）

#### P 值的含义与局限（2:30-3:15）

**[画面]**：展示 P 值 = 0.05 的阈值线，标注显著性区域

**[解说词]**：
> "P 值是统计检验的核心指标，但经常被误解。P 值小于 0.05 表示在零假设成立的情况下，观察到当前或更极端结果的概率小于 5%。它不等于组间差异的概率，也不等于研究结论正确的概率。P 值只是提供了反对零假设的证据强度。"

**[画面]**：展示小样本 + 大效应 vs 大样本 + 小效应的对比

**[解说词]**：
> "这里有一个重要的陷阱：大样本量时，即使很小的差异也能获得显著的 P 值，但生物学意义可能不大。相反，小样本量时，即使观察到很大的差异，P 值也可能不显著，这可能是因为检验效能不足。因此，不能仅依赖 P 值，必须结合效应量。"

#### 效应量的重要性（3:15-4:00）

**[画面]**：展示效应量分类表

| 效应量 | 小效应 | 中等效应 | 大效应 |
|-------|-------|---------|-------|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| log2FC | 0.5 | 1.0 | 2.0 |
| LDA Score | 2.0 | 3.0 | 4.0 |
| R² | 0.1 | 0.25 | 0.5 |

**[解说词]**：
> "效应量衡量差异的实际大小，不受样本量影响。这是判断生物学重要性的关键指标。比如 log2FoldChange 为 2，意味着差异倍数是 4 倍，这是很大的生物学效应。而 log2FoldChange 为 0.1，差异倍数只有 1.07 倍，即使 P 值显著，生物学意义也有限。"

**[画面]**：展示 Meta2bAnalyst 结果表格中的效应量列

**[解说词]**：
> "Meta2bAnalyst 的结果表格中包含了多种效应量指标。在解读结果时，请同时关注 P 值和效应量。一个可靠的研究发现应该同时具备统计显著性和足够的效应量。"

#### 多重检验校正（4:00-4:30）

**[画面]**：展示未校正 vs 校正后的 P 值对比

**[解说词]**：
> "微生物组分析通常同时检验成百上千个特征，这会导致多重比较问题。如果不校正，即使所有特征都无差异，也预期有约 5% 的特征出现假阳性。Meta2bAnalyst 默认使用 BH 方法进行 FDR 校正，控制假发现率。论文中应该报告校正后的 P 值，即 padj 或 q 值。"

### 第四部分：论文写作规范（7:00-9:00）

#### 方法部分描述（7:00-7:45）

**[画面]**：展示论文 Methods 部分的示例段落

**[解说词]**：
> "在论文的方法部分，需要详细描述分析流程，让读者可以复现您的结果。请包括以下信息：软件名称和版本号、数据预处理步骤（过滤和标准化参数）、统计方法名称、多重检验校正方法、显著性阈值。"

**[画面]**：展示方法描述模板

> "Statistical analysis was performed using Meta2bAnalyst (v1.0). Feature tables were filtered with a minimum count threshold of 4 and a prevalence threshold of 20%. Data normalization was performed using Total Sum Scaling (TSS). Alpha diversity was calculated using the Shannon and Simpson indices, and group differences were tested using the Wilcoxon rank-sum test with Benjamini-Hochberg FDR correction. Differential abundance analysis was performed using DESeq2 with a significance threshold of adjusted P < 0.05."

**[解说词]**：
> "这是一个标准的方法描述模板。请根据您实际使用的参数修改具体内容。清晰的方法描述不仅有助于审稿人理解，也方便其他研究者复现您的研究。"

#### 结果部分描述（7:45-8:45）

**[画面]**：展示论文 Results 部分的示例段落，标注关键要素

**[解说词]**：
> "结果部分应该客观描述图表中的发现，避免过度解读。关键要素包括：使用的统计方法、样本量、显著性水平和效应量。例如：'Treatment group showed significantly higher Shannon diversity compared to Control group (Wilcoxon test, P = 0.003, Cohen's d = 0.85).'"

**[画面]**：展示错误描述 vs 正确描述对比

| 错误描述 | 正确描述 |
|---------|---------|
| "Treatment 显著提高了多样性" | "Treatment 组的 Shannon 指数中位数高于 Control 组（Wilcoxon 检验，P = 0.003）" |
| "A 物种是对照组的标志物" | "A 物种在 Control 组中显著富集（LEfSe，LDA = 3.2，P = 0.01）" |
| "群落结构完全不同" | "两组群落结构存在显著差异（PERMANOVA，R² = 0.25，P = 0.001）" |

**[解说词]**：
> "注意避免模糊的描述。不要说'显著提高了多样性'，而要说明具体指标、统计方法和 P 值。不要说'完全不同'，而要给出 R 平方值，表示分组解释了多少差异。精确的语言是科学论文的基本要求。"

(A) Shannon diversity index was significantly higher in the Treatment group compared to the Control group (Wilcoxon test, ***P < 0.001).
