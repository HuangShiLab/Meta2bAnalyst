## 1. 系统概述与界面导航

### 1.1 界面布局

Meta2bAnalyst 采用单页应用（SPA）架构，主要界面区域包括：

[Screenshot: 主界面布局，标注顶部导航栏、左侧步骤指示器、主内容区]

- **顶部导航栏**: 项目名称、当前步骤提示、帮助链接
- **左侧步骤指示器**: 显示当前所在的分析步骤（Upload → Inspect → Filter → Normalize → Analyze → Export）
- **主内容区**: 当前步骤的操作面板和结果展示区
- **状态提示区**: 底部显示操作成功/失败提示、加载状态

### 1.2 分析流程概览

完整的分析工作流包含 6 个严格顺序的步骤：

```
数据上传 (Upload) → 数据检查 (Inspect) → 数据过滤 (Filter) → 标准化 (Normalize) → 分析 (Analyze) → 导出 (Export)
```

每个步骤必须完成后才能进入下一步。左侧步骤指示器会显示当前步骤的完成状态（✓ 已完成 / ○ 进行中 / 未开始）。

## 2. 数据准备

### 2.1 数据格式要求

在上传数据前，请确保您的数据符合以下格式要求。详细格式规范请参阅 README.md 的"支持的输入格式详解"部分。

#### 2.1.1 特征表（Feature Table）

- 格式：CSV 或 TSV
- 第一行：以 `#NAME` 开头，后接所有样本名（逗号或制表符分隔）
- 第一列：特征名（如 OTU_1, species_name, KO_number）
- 数据值：非负整数（丰度计数）
- 样本名：不含空格、特殊字符，建议仅使用字母、数字和下划线

**示例（CSV）：**
```csv
#NAME,Sample1,Sample2,Sample3
OTU_1,100,150,80
OTU_2,50,0,120
OTU_3,200,180,90
```

**常见错误：**
- ❌ 第一行没有 `#NAME` 标记
- ❌ 样本名包含空格（如 `Sample 1`）
- ❌ 数值包含小数或负数（计数数据应为整数）
- ❌ 样本名大小写不一致（如特征表用 `Sample1`，元数据用 `sample1`）

#### 2.1.2 元数据（Metadata）

- 格式：CSV 或 TSV
- 第一行：以 `#NAME` 开头，后接所有样本名
- 第一列：样本名（必须与特征表列名完全一致，大小写敏感）
- 后续列：分组变量（如 Treatment, Group, Site）
- **每组至少 3 个重复样本**（统计检验的最小要求）

**示例（CSV）：**
```csv
#NAME,Sample1,Sample2,Sample3
Sample1,Control,SiteA
Sample2,Treatment,SiteA
Sample3,Treatment,SiteB
```

**常见错误：**
- ❌ 元数据包含特征表中没有的样本（未匹配样本将被排除）
- ❌ 分组变量各组样本数不足 3 个（无法进行统计检验）
- ❌ 使用连续变量作为分组变量（需先离散化）

#### 2.1.3 分类注释（Taxonomy，可选）

- 格式：CSV 或 TSV
- 两列：特征名、分类注释
- 分类注释格式：`k__Bacteria;p__Firmicutes;c__Bacilli;o__Lactobacillales;f__Lactobacillaceae;g__Lactobacillus;s__rhamnosus`

### 2.2 数据检查清单

上传前请确认：
- [ ] 特征表和元数据的样本名完全匹配（大小写敏感）
- [ ] 每组至少 3 个重复样本
- [ ] 特征表值为非负整数
- [ ] 元数据至少有一列分组变量
- [ ] 无缺失样本名或空值

## 3. 模块一：数据上传与验证

### 3.1 选择分析模块

进入主界面后，您会看到四个分析模块卡片：

[Screenshot: 主界面，四个分析模块卡片]

| **株水平分析** | 菌株水平组成与差异 | Strain2bScan / Tag2bMap 输出 |
| **多组学整合** | 物种-功能-株联合分析 | 上述多维度数据同时上传 |

**操作步骤：**
1. 点击选择分析模块卡片
2. 选择数据格式（2bRAD-M / QIIME / Mothur / 通用 CSV）

### 3.2 上传文件

[Screenshot: 文件上传区域，显示拖拽区域和文件列表]

| 格式 | 必需文件 | 可选文件 |
|------|---------|---------|
| 2bRAD-M | species_abundance.csv, metadata.csv | functional_genes.csv, strain_profile.csv |
| QIIME | feature-table.biom, metadata.csv | taxonomy.tsv |
| Mothur | *.shared, *.taxonomy, metadata.csv | — |
| 通用 CSV | feature_table.csv, metadata.csv | taxonomy.csv |

### 3.3 验证结果

验证完成后，系统显示：
- ✓ 文件格式验证通过
- ✓ 特征表读取成功（N 特征 × M 样本）
- ✓ 元数据读取成功（M 样本 × P 变量）
- ⚠ 警告信息（如有）

如果验证失败，请根据错误提示修正数据格式后重新上传。

**常见验证错误及解决：**

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| "样本名不匹配" | 特征表与元数据样本名不一致 | 检查大小写、空格、特殊字符 |
| "分组样本数不足" | 某组样本 < 3 | 增加样本或合并组别 |
| "特征表含非数值" | 数据区域含文本或空值 | 清理数据，确保全为整数 |
| "元数据缺少分组变量" | 仅有一列样本名 | 添加至少一列分组变量 |
| "BIOM 格式错误" | BIOM 文件损坏或版本不支持 | 使用 QIIME 2 导出的标准 BIOM 文件 |

## 4. 模块二：数据检查

### 4.1 检查界面

[Screenshot: 数据检查页面，包含四个信息面板]

数据检查页面包含以下信息面板：

#### 4.1.1 样本匹配状态

显示特征表与元数据的样本匹配情况：
- **Matched Samples**: 成功匹配的样本数（绿色）
- **Unmatched in Feature Table**: 仅在特征表中的样本（黄色）
- **Unmatched in Metadata**: 仅在元数据中的样本（红色）

> 理想情况：Matched Samples = 总样本数，Unmatched = 0

**处理建议：**
- 若有未匹配样本，检查样本名大小写和特殊字符
- 若未匹配样本过多，请返回上传步骤重新准备数据

#### 4.1.2 数据概览统计

| 统计项 | 说明 | 参考范围 |
|-------|------|---------|
| 特征数 (Features) | 特征表中的行数（OTU/ASV/物种/基因） | 通常 100-5000 |
| 样本数 (Samples) | 成功匹配的样本数 | 根据实验设计 |
| 总读数 (Total Reads) | 所有样本的计数总和 | 取决于测序深度 |
| 稀疏度 (Sparsity) | 零值占矩阵的比例 | < 90% 为宜，过高需过滤 |
| 平均特征数/样本 | 每样本平均非零特征数 | 建议 > 50 |
| 最小/最大 Library Size | 样本最小/最大计数总和 | 差异 < 10 倍为宜 |

#### 4.1.3 Library Size 分布

柱状图展示各样本的测序总量（Library Size）。

[Screenshot: Library Size 分布柱状图]

**解读：**
- 各样本 Library Size 应较为接近（差异 < 10 倍）
- 若有明显偏低的样本（< 平均值的 1/5），建议在上游分析中去除或在本平台的过滤步骤中处理
- 严重不均的数据可能影响差异分析结果

#### 4.1.4 分组变量预览

展示元数据中的分组变量及各组样本数。

[Screenshot: 分组变量预览表格]

**检查要点：**
- 各组样本数是否 ≥ 3（统计检验要求）
- 分组是否均衡（避免某组仅 1-2 个样本）
- 分组变量是否正确识别（如 Treatment 应为分类变量而非连续变量）

### 4.2 进入下一步

确认数据检查无误后，点击 **"Proceed to Filter"** 进入数据过滤步骤。

## 5. 模块三：数据过滤

### 5.1 过滤界面

[Screenshot: 过滤参数设置面板，包含低计数过滤、低方差过滤、Top N 筛选三个区域]

数据过滤旨在去除低质量、低丰度或低变异的特征，减少噪声并提高统计检验效能。

### 5.2 低计数过滤（Low Count Filtering）

去除在大多数样本中丰度极低或出现频率过低的特征。

| 参数 | 说明 | 默认值 | 推荐范围 | 调整建议 |
|------|------|-------|---------|---------|
| **最小计数 (Min Count)** | 特征在单个样本中的最小丰度阈值 | 4 | 1-10 | 原始计数数据推荐 2-5；已标准化数据可设为 0.001 |
| **Prevalence** | 特征需出现在至少 % 的样本中 | 20% | 10%-50% | 大样本研究（>100）可降至 10%；小样本研究（<20）可升至 30% |

**原理说明：**
- 只出现在极少数样本中的特征可能是测序错误、污染或极低丰度的稀有物种
- 去除这些特征可减少多重检验校正的压力，提高差异检验的统计效能

**推荐配置：**
- 样本量 10-30：Min Count = 4, Prevalence = 20%
- 样本量 30-100：Min Count = 2, Prevalence = 15%
- 样本量 > 100：Min Count = 2, Prevalence = 10%

### 5.3 低方差过滤（Low Variance Filtering）

去除在所有样本中变化幅度很小的特征（即几乎恒定的特征）。

| 参数 | 说明 | 默认值 | 推荐范围 | 调整建议 |
|------|------|-------|---------|---------|
| **移除最低方差比例** | 移除方差最低的 X% 特征 | 10% | 0%-20% | 若特征数过多（>5000）可升至 20%；特征数少时设为 0% 保留所有 |

**原理说明：**
- 方差几乎为零的特征在所有样本中丰度相似，不太可能携带组间差异信息
- 去除这些特征可减少维度，提高后续分析效率

### 5.4 Top N 筛选（可选）

仅保留丰度最高的 N 个特征，用于快速预览或特定分析。

| 参数 | 说明 | 默认值 | 推荐范围 |
|------|------|-------|---------|
| **Top N** | 保留丰度最高的 N 个特征 | 不启用 | 50-500（仅用于快速预览） |

> ⚠️ **注意**：Top N 筛选会丢失信息，仅在探索性分析或特定热图绘制时使用，正式差异分析不建议启用。

### 5.5 应用过滤

1. 设置过滤参数
2. 点击 **Submit** 按钮
3. 系统显示过滤前后对比：
   - 过滤前：N 特征 × M 样本
   - 过滤后：N' 特征 × M 样本
   - 移除特征数：N - N'

[Screenshot: 过滤前后对比统计表格]

4. 确认结果合理后，点击 **"Proceed to Normalize"** 进入标准化

**过滤结果判断：**
- 若移除特征数 > 80%，说明过滤过于严格，建议放宽参数
- 若移除特征数 < 5%，说明过滤过于宽松，建议收紧参数（尤其稀疏数据）
- 理想范围：移除 20%-60% 特征

## 6. 模块四：数据标准化

### 6.1 标准化界面

[Screenshot: 标准化方法选择界面，显示 TSS/CSS/UQ/CLR/RLE/TMM 六个选项卡]

### 6.2 标准化方法选择

选择适合您的分析类型的标准化方法。各方法的详细说明如下：

#### 6.2.1 TSS (Total Sum Scaling) — 总和标准化

**原理：** 将每个样本的计数总和缩放到相同值（通常 1 或 100）。

**公式：** $x'_{ij} = \frac{x_{ij}}{\sum_j x_{ij}} \times C$

**适用场景：**
- Alpha 多样性分析（Shannon, Simpson 等）
- Beta 多样性（Bray-Curtis）
- 物种组成堆叠柱状图

**优点：** 简单直观，保留相对丰度信息
**缺点：** 受高丰度特征影响，对极端值敏感

**推荐配置：** 分析群落结构和多样性时作为默认选择

#### 6.2.2 CSS (Cumulative Sum Scaling) — 累积和标准化

**原理：** 基于样本中特征丰度的累积分布，选择一个分位数作为标准化因子，对高丰度异常值更稳健。

**适用场景：**
- 差异分析前的探索性可视化
- 成分数据的标准化

**优点：** 对高丰度异常值稳健
**缺点：** 参数选择需要经验

**推荐配置：** 当数据中存在明显的异常高丰度样本时使用

#### 6.2.3 UQ (Upper Quartile) — 上四分位数标准化

**原理：** 使用样本中特征丰度的上四分位数（75% 分位数）作为标准化因子。

**适用场景：**
- 差异分析
- 有偏分布数据的标准化

**优点：** 对高丰度特征稳健，适合 RNA-seq / 宏基因组数据
**缺点：** 当大量特征丰度为零时，上四分位数可能不稳定

**推荐配置：** 数据分布严重右偏时使用

#### 6.2.4 CLR (Centered Log-Ratio) — 对数比转换

**原理：** 对成分数据进行对数比转换，处理组成数据的约束性（所有成分之和为常数）。

**公式：** $x'_{ij} = \log(x_{ij}) - \frac{1}{D}\sum_{d=1}^{D}\log(x_{id})$

**适用场景：**
- 相关性分析（特征间相关性）
- 网络分析（Co-occurrence 网络）
- 主成分分析（PCA）

**优点：** 适合成分数据，消除总和约束带来的虚假相关性
**缺点：** 要求无零值（需先进行伪计数处理，如加 1）

> ⚠️ **注意**：使用 CLR 时，系统会自动对零值添加伪计数（默认加 1）。若数据零值过多（>50%），CLR 可能不适用。

**推荐配置：** 构建相关性网络或进行 PCA 时必选

#### 6.2.5 RLE (Relative Log Expression) — 相对对数表达

**原理：** 参考 DESeq2 的标准化方法，计算每个特征在所有样本中的中位数比值。

**适用场景：**
- 差异分析（配合 DESeq2 使用）
- 原始计数数据的标准化

**优点：** 假设大多数特征无差异，适合差异分析
**缺点：** 若大部分特征在不同组间都有差异，标准化可能不准确

**推荐配置：** 使用 DESeq2 进行差异分析时推荐搭配使用

#### 6.2.6 TMM (Trimmed Mean of M-values) — 截尾 M 值均值

**原理：** 参考 edgeR 的标准化方法，计算样本间特征丰度比值的截尾均值。

**适用场景：**
- 差异分析（配合 edgeR 使用）
- 样本间存在显著组成差异时

**优点：** 对极端差异样本稳健
**缺点：** 计算较复杂

**推荐配置：** 使用 edgeR 进行差异分析时推荐搭配使用

### 6.3 标准化方法选择指南

| 分析类型 | 推荐标准化方法 | 备选方法 | 不推荐方法 |
|---------|--------------|---------|-----------|
| Alpha 多样性 | TSS, CSS | UQ | CLR（会改变多样性指数含义） |
| Beta 多样性 (Bray-Curtis) | TSS, CSS | UQ | — |
| 差异分析 (DESeq2) | 原始计数 或 RLE | TMM | CLR, TSS |
| 差异分析 (edgeR) | 原始计数 或 TMM | RLE | CLR, TSS |
| 差异分析 (t-test/Wilcoxon) | TSS, CSS | UQ | — |
| 相关性/网络分析 | CLR | — | TSS, UQ |
| 聚类/PCA | CLR, TSS | CSS | — |
| 机器学习 | TSS, CSS | UQ | CLR（若模型不支持负值） |

> ⚠️ **重要提示**：
> - **Scaling 和 Transformation 方法互斥**：TSS/CSS/UQ 属于 Scaling（缩放），CLR 属于 Transformation（转换）。一次分析只能选择一种类型。
> - DESeq2 和 edgeR 要求使用原始计数或专门的标准化方法（RLE/TMM），**不要**预先使用 TSS/CSS/CLR 转换后再输入 DESeq2/edgeR。

### 6.4 应用标准化

1. 选择标准化方法
2. 阅读方法说明和适用提示
3. 点击 **Submit** 应用标准化
4. 查看标准化后数据预览（前 5 行 × 5 列）
5. 确认数据范围合理（如 TSS 后每列和接近 1 或 100）
6. 点击 **"Proceed to Analysis"** 进入分析

## 7. 模块五：分析执行

### 7.1 分析界面

[Screenshot: 分析页面，左侧为分析类型列表，右侧为参数配置面板]

分析页面分为左右两栏：
- **左侧**：分析类型选择（群落分析 / 差异分析 / 聚类与网络 / 机器学习）
- **右侧**：分析参数配置和分组变量选择

### 7.2 分析类型详解

#### 7.2.1 群落分析（Community Analysis）

##### Alpha 多样性

评估单个样本内的微生物多样性。

**配置参数：**

| 参数 | 说明 | 默认值 | 选项 |
|------|------|-------|------|
| **多样性指数** | 选择要计算的多样性指数 | Shannon, Simpson | Shannon, Simpson, Chao1, ACE, Observed, Pielou |
| **分组变量** | 用于分组比较的分组变量 | 第一个分组变量 | 元数据中的所有分类变量 |
| **统计检验** | 组间比较方法 | Wilcoxon (两组) / Kruskal-Wallis (多组) | t-test, Wilcoxon, ANOVA, Kruskal-Wallis |

**操作步骤：**
1. 选择 Alpha 多样性
2. 勾选要计算的多样性指数（可多选）
3. 选择分组变量
4. 选择统计检验方法
5. 点击 **运行分析**

**结果展示：**
- 箱线图：展示各组的多样性指数分布
- 统计表格：各组均值、标准差、P 值、效应量
- 若检验显著，标注 *（P<0.05）、**（P<0.01）、***（P<0.001）

[Screenshot: Alpha 多样性结果页面，包含箱线图和统计表格]

**结果解读：**
- 箱线图显示各组多样性中位数和分布范围
- 若箱线图不重叠且 P < 0.05，说明组间存在显著差异
- 注意：Pielou 均匀度范围 0-1，接近 1 表示群落更均匀

#### 7.2.2 差异分析（Differential Analysis）

##### 组间差异检验（Feature Level）

检验单个特征（OTU/物种/基因）在不同组间的丰度差异。

**配置参数：**

| 参数 | 说明 | 默认值 | 选项 |
|------|------|-------|------|
| **检验方法** | 统计检验方法 | Wilcoxon (两组) | t-test, Wilcoxon, ANOVA, Kruskal-Wallis, DESeq2, edgeR |
| **分组变量** | 用于分组的变量 | 第一个分组变量 | 元数据中的所有分类变量 |
| **多重检验校正** | 校正方法 | BH (FDR) | BH, Bonferroni, none |
| **显著性阈值** | 校正后 P 值阈值 | 0.05 | 0.01-0.1 |

**操作步骤：**
1. 选择差异分析
2. 选择检验方法
3. 选择分组变量

5. 设置显著性阈值
6. 点击 **运行分析**

**结果展示：**
- 火山图：X 轴为 log2FoldChange，Y 轴为 -log10(Pvalue)，每个点为一个特征

**结果解读：**
- 火山图中右侧（log2FC > 0）且上方（P 值小）的点表示在组 2 中显著富集的特征
- 左侧（log2FC < 0）且上方的点表示在组 1 中显著富集的特征
- 颜色标记显著性：红色 = 显著上调，蓝色 = 显著下调，灰色 = 不显著
- 表格中按校正后 P 值排序，优先关注 P.adjust < 0.05 且 |log2FC| > 1 的特征

**方法选择建议：**

| 场景 | 推荐方法 | 原因 |
|------|---------|------|
| 两组比较，样本 < 30 | Wilcoxon | 非参数，不假设正态分布 |
| 两组比较，样本 ≥ 30 | t-test 或 Wilcoxon | 大样本时两者结果相近 |
| 多组比较，探索性 | Kruskal-Wallis | 非参数，可发现多组差异 |
| 严格控制假阳性 | DESeq2 | 保守，基于负二项分布 |
| 高检验效能 | edgeR | 较敏感，适合发现 subtle 差异 |
| 多组生物标志物 | LEfSe | 两步骤筛选，效应大小排序 |

## 9. 株水平分析专题

### 9.1 株水平分析概述

株水平分析是 Meta2bAnalyst 的特色功能，基于 Strain2bScan 或 Tag2bMap 的输出数据，揭示同一物种内不同株（strain）的组成、多样性和差异。

> 株（Strain）是物种（Species）以下的分类单元，同一物种的不同株可能具有不同的功能特征、致病性或环境适应性。株水平分析对于追踪菌株来源、评估定植稳定性和识别功能差异株具有重要意义。

### 9.2 数据要求

进行株水平分析需要上传：
- **株水平组成表**：物种 × 株的丰度矩阵（Strain2bScan 输出）
- **元数据**：样本分组信息
- **可选**：ANI 矩阵（Tag2bMap 输出，用于株间相似性分析）

[Screenshot: 株水平分析数据上传界面]

### 9.3 株组成分析

**功能**：展示每个样本中各物种的株组成谱。

**结果展示**：
- 堆叠柱状图：每个样本中各物种的株组成（不同颜色代表不同株）

[Screenshot: 株组成分析结果]

**结果解读**：

## 11. 结果解读指南

### 11.1 统计显著性判断

| 符号 | P 值范围 | 含义 | 解读建议 |
|------|---------|------|---------|
| ns | P ≥ 0.05 | 不显著 | 无统计学差异，生物学差异可能为随机波动 |
| * | 0.01 ≤ P < 0.05 | 显著 | 存在统计学差异，但需谨慎解读 |
| ** | 0.001 ≤ P < 0.01 | 非常显著 | 较可靠的差异，建议结合效应量判断 |
| *** | P < 0.001 | 极显著 | 高度可靠的差异 |

> **重要提醒**：统计显著性 ≠ 生物学重要性。请结合效应量（Effect Size）和生物学背景综合判断。

### 11.2 效应量判断

| 效应量指标 | 小效应 | 中等效应 | 大效应 |
|----------|-------|---------|-------|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| log2FoldChange | 0.5 | 1.0 | 2.0 |
| LDA Score (LEfSe) | 2.0 | 3.0 | 4.0 |
| R² (PERMANOVA) | 0.1 | 0.25 | 0.5 |

**判断原则**：
- 小效应量 + 大样本量 → 可能获得显著 P 值，但生物学意义有限
- 大效应量 + 小样本量 → 即使 P 值不显著，也值得关注
- 推荐同时报告 P 值和效应量

### 11.3 图表解读速查

| 图表类型 | 核心信息 | 判断要点 |
|---------|---------|---------|
| 箱线图 | 中位数、分布范围、异常值 | 中位数差异明显 + P < 0.05 = 显著差异 |
| 散点图 (PCoA) | 样本相似性、分组聚类 | 同组聚类 + PERMANOVA P < 0.05 = 群落结构差异 |
| 火山图 | 差异倍数 + 显著性 | 右上角/左上角 = 显著差异特征 |
| 热图 | 丰度模式、聚类关系 | 同组聚类 = 组内模式相似 |
| 网络图 | 特征关联、模块结构 | 紧密簇 = 共现组合；负相关 = 互斥关系 |
| 柱状图 (LEfSe) | 标志物 + 效应大小 | LDA > 2 且 P < 0.05 = 可靠标志物 |

### 11.4 论文图表规范

投稿前请确保您的图表符合期刊规范：

- **分辨率**：位图 ≥ 300 DPI，矢量图推荐 SVG / PDF
- **颜色**：避免仅使用颜色区分（考虑色盲读者），使用形状+颜色组合
- **字体**：图表内文字 ≥ 8 pt，标签 ≥ 10 pt
- **图例**：清晰完整，包含统计检验方法和显著性标记
- **统计标注**：在图表上标注 P 值或 * 符号，并在图注说明检验方法

## 12. 故障排除

### 12.1 上传阶段错误

| 错误 | 可能原因 | 解决方法 |
|------|---------|---------|
| "文件格式不支持" | 文件扩展名不正确 | 确保文件为 .csv, .tsv, .biom, .shared, .taxonomy |
| "文件解析失败" | 编码问题或格式错误 | 使用 UTF-8 编码，检查分隔符是否统一 |
| "特征表为空" | 文件只有标题行 | 检查数据文件是否包含有效数据行 |
| "元数据缺少样本名" | 第一行格式错误 | 确保第一行以 `#NAME` 开头 |
| "样本名不匹配" | 大小写或空格不一致 | 清理样本名，确保完全一致 |
| "上传文件过大" | 超过 100MB 限制 | 压缩文件或分批上传，或修改环境变量 |

### 12.2 验证阶段错误

| 错误 | 可能原因 | 解决方法 |
|------|---------|---------|
| "分组样本数不足" | 某组 < 3 个样本 | 合并小组别或增加样本 |
| "特征表含非数值" | 数据中有文本或空值 | 替换空值为 0，确保数值区域全为数字 |
| "所有样本未匹配" | 样本名完全不一致 | 检查样本名拼写和格式 |
| "Library Size 为 0" | 某样本计数全为 0 | 在上游分析中去除该样本 |

### 12.3 分析阶段错误

| 错误 | 可能原因 | 解决方法 |
|------|---------|---------|
| "分析超时" | 数据量过大或服务器负载高 | 减少特征数（过滤更严格）或稍后重试 |
| "DESeq2 失败" | 样本量过小或数据不符合负二项分布 | 增加样本量或改用 Wilcoxon |
| "网络分析无结果" | 相关性阈值过高 | 降低 P 值或相关性阈值 |
| "LEfSe 无显著标志物" | 组间差异较小 | 降低 LDA 阈值或检查分组变量 |
| "内存不足" | 数据矩阵过大 | 过滤更多低丰度特征，或增加服务器内存 |
| "Random Forest 过拟合" | 特征数 >> 样本数 | 增加样本或减少特征（Top N 筛选） |

### 12.4 结果异常排查

| 异常现象 | 可能原因 | 解决方法 |
|---------|---------|---------|
| 所有 P 值都不显著 | 组间差异确实很小，或样本量不足 | 增加样本量，或检查分组变量是否合理 |
| 所有 P 值都极显著 | 多重检验校正未生效，或存在批次效应 | 检查是否使用了校正方法，排查批次变量 |
| PCoA 中样本完全重叠 | 群落组成非常相似，或标准化方法不当 | 尝试不同的 Beta 多样性距离 |
| 火山图呈三角形 | 低丰度特征波动大，或标准化过度 | 使用更严格的低计数过滤 |
| 网络图过于密集 | 相关性阈值过低 | 提高 P 值或相关性阈值 |
| 网络图完全空白 | 相关性阈值过高，或无显著相关性 | 降低阈值，或检查数据是否过标准化 |

### 12.5 系统问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 页面无法加载 | 后端服务未启动 | 检查 Docker 容器或后端服务状态 |
| 分析进度卡住 | 网络中断或后端任务失败 | 刷新页面，重新运行分析 |
| 会话过期 | 30 分钟无操作 | 重新上传数据，系统已自动清理 |
| 图表无法显示 | 浏览器缓存问题 | 清除浏览器缓存或换浏览器重试 |
| 导出失败 | 文件过大或网络问题 | 分次导出，或检查网络连接 |

### 13.2 标准化方法选择速查

| 下游分析 | 推荐方法 | 次选方法 | 禁忌方法 |
|---------|---------|---------|---------|
| Alpha 多样性 | TSS | CSS | CLR |
| Beta 多样性 (Bray-Curtis) | TSS | CSS | — |
| 差异分析 (DESeq2) | 原始计数 / RLE | TMM | TSS, CLR |
| 差异分析 (edgeR) | 原始计数 / TMM | RLE | TSS, CLR |
| 差异分析 (t-test/Wilcoxon) | TSS | CSS | — |
| 网络/相关性 | CLR | — | TSS |
| 聚类/PCA | CLR | TSS | — |
| Random Forest | TSS | CSS | CLR (若不支持负值) |

### 13.3 统计检验选择速查

| 比较组数 | 样本分布 | 推荐方法 | 备选方法 |
|---------|---------|---------|---------|
| 2 组 | 正态/大样本 | t-test | Wilcoxon |
| 2 组 | 非正态/小样本 | Wilcoxon | — |
| 多组 | 正态/大样本 | ANOVA | Kruskal-Wallis |
| 多组 | 非正态/小样本 | Kruskal-Wallis | — |
| 多组/标志物 | 任意 | LEfSe | — |
| 原始计数/严格 | 任意 | DESeq2 | edgeR |
| 原始计数/探索 | 任意 | edgeR | DESeq2 |
