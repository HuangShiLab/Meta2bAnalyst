# Meta2bAnalyst 学生使用指南

一站式微生物组 / 多组学统计分析平台 + AI Agent 助手

**访问地址：** http://localhost:8080 （课堂/局域网部署时以老师提供的网址为准）

---

## 1. 快速开始：三种使用方式

| 方式 | 需要什么 | 能做什么 |
|---|---|---|
| **游客模式** | 什么都不需要 | 浏览所有页面；对内置 demo 数据跑分析；和 Agent 对话探索数据 |
| **学生账号** | 老师发的用户名 + 初始密码 | 游客的全部功能 + 上传自己的数据、保存自己的分析会话（每人 500 MB） |
| **Demo 数据集** | 登录后点一下即可 | 一键载入 mBio 2021 牙龈炎纵向多组学研究的 4 类数据集 |

> 建议第一次用时先用**游客模式**熟悉界面，再登录上传自己的数据。

---

## 2. 登录

1. 打开网址后点右上角 **Sign in**（或访问需要登录的功能时会自动跳转）。
2. 输入老师发给你的用户名和初始密码（初始密码统一为 `123456`）。
3. **首次登录后请立刻修改密码**：左侧菜单 **My Data** → 页面底部 *Change password*。

未登录时右上角显示 **Guest**；登录后显示你的用户名。

---

## 3. Demo 数据（mBio 2021 牙龈炎多组学研究）

平台内置 Huang *et al.*, mBio 2021（doi:10.1128/mbio.03281-20）的真实数据，分四类：

| Demo 数据集 | 内容 |
|---|---|
| **Microbiome** | 菌属水平 feature table + metadata（261 个牙菌斑样本） |
| **Metabolome** | 代谢物 feature table + metadata |
| **Multi-omics** | 微生物组 + 代谢组联合（4 个文件） |
| **Multi-site-multi-omics** | 多部位多组学 |

**使用入口（二选一）：**

- **Agent 页（推荐）**：右上角 *Load demo dataset* 下拉框选一类，自动创建会话并载入数据；已载入的 demo 会话在会话列表里可直接选用（游客也能用）。
- **分析页**：Microbiome / Multi-omics / Multi-site 页顶部选择已有 demo 会话。

---

## 4. 推荐的上手流程（10 分钟）

1. 进入 **Agent** 页，载入 *Demo – Microbiome (mBio 2021)*。
2. 在对话框里用自然语言提问，中英文都可以，例如：
   - *"做 Bray-Curtis PCoA，按 Visit 上色，按 Bleeding 映射点大小"*
   - *"比较不同 visit 之间的 alpha 多样性"*
   - *"哪些菌在牙龈炎进展中富集？"*
3. Agent 会给出**分析计划**（每一步用什么方法、什么参数），确认后执行并出图。
4. 图可以下载 PNG/SVG；结果在 **Results** 页汇总。

也可以不用 Agent，直接在 **Microbiome / Multi-omics** 页面手动点选分析模块，参数均可调。

## 5. 上传自己的数据（需登录）

左侧 **Upload** 页。核心规则（很重要，上传前请读）：

### 单一组学 = 至少 2 个文件
- **Feature table**（行=特征/菌/代谢物，列=样本，或反向，平台会自动识别方向）
- **Metadata**（行=样本，至少一列样本 ID + 分组/表型列）
- 两个文件的**样本 ID 必须一致**。平台会自动检查并报告匹配的样本数；不一致会报错提示。

### 多组学 = n × 2 个文件
- 每个组学各自的 feature table + metadata；或者 **1 个统一 metadata + n 个 feature table**。
- 所有文件之间的样本 ID 都要一致，上传后平台会逐一核对。

### 代谢组特别提示
- pos / neg 等多个 feature table 可以**分开分析**，也可以**合并**为一个表分析。
- 合并时丰度归一化在**每个样品内部**进行（避免不同离子模式互相稀释）。

### 上传后
1. **Inspection** 页检查数据（样本数、特征数、稀疏度、metadata 匹配情况）。
2. 然后到对应分析页跑分析。
3. 你的会话和文件都在 **My Data** 页管理（可删除释放配额）。

**配额：每人 500 MB。** 超限会提示已用量，删除旧会话即可释放。

## 6. 遇到问题 / 提交反馈

请把以下内容发给老师（截图 + 文字）：

1. 你在哪个页面、点了什么；
2. 用的是哪个会话（demo 还是自己上传的，什么数据）；
3. 报错信息全文或"没有反应"的具体现象；
4. 如果是图的问题：期望看到什么 vs 实际看到什么。

Agent 相关的反馈尤其欢迎：比如你输入的自然语言它理解错了、分析计划不合理、图和预期不符等。

## 7. 常见问题

**Q：忘记密码怎么办？**
找老师重置（管理员可以删除后重建账号；自己的会话数据会保留为共享，不受影响）。

**Q：别人能看到我的数据吗？**
不能。你的会话只有你自己（和管理员）可见。内置 demo 会话是所有人共享的。

**Q：退出登录 / 会话过期？**
Token 有效期 72 小时，过期后重新登录即可，数据不会丢。

**Q：可以用中文和 Agent 对话吗？**
可以。界面是英文的，但 Agent 理解中文提问没问题。
